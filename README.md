# NetMatch — AI-сервис умного нетворкинга

Подсказывает участнику IT-мероприятия **5 человек, с кем стоит познакомиться**, и объясняет почему.
Трек: AI for Digital Economy & Smart Business.

## Запуск

```bash
docker compose up --build
```
Откройте http://localhost:8000 (подбор) и http://localhost:8000/dashboard (дашборд организатора).

Без Docker:
```bash
pip install -r requirements.txt
python data/generate_profiles.py --n 200   # пересоздать базу анкет (необязательно)
cd app && python main.py
```

LLM-объяснения необязательны: скопируйте `.env.example` в `.env` и укажите `LLM_API_KEY`
(подходит любой OpenAI-совместимый API). Без ключа объяснения строятся по шаблонам из фактов анкеты.
Ключи в репозиторий не попадают (`.env` в `.gitignore`).

## Что умеет

| Требование | Где |
|---|---|
| Анкета: роль, стек, опыт, интересы, «о себе», цель из 6 вариантов | `app/static/index.html` |
| Топ-5 с объяснением в 1–2 предложения | `app/recommender.py`, `app/explain.py` |
| Взаимность целей (соискателю — нанимающих) | матрица `GOAL_MATRIX` + скор в обе стороны |
| Веб-интерфейс | `/` |
| 200 синтетических анкет | `data/profiles.json`, `data/profiles.csv` |
| Казахский, русский, английский | переключатель в шапке; объяснения на выбранном языке |
| Первая фраза для знакомства | под каждой рекомендацией, кнопка «Копировать» |
| Фидбек «познакомились / не подошло» и пересчёт | причина отказа снижает вес похожих кандидатов |
| Расписание 1:1 по свободным слотам | каждой рекомендации — общий слот без пересечений |
| Дашборд организатора: карта интересов | `/dashboard` |
| NFC/QR-бейджи: приложил телефон к бейджу и видишь совместимость | `/p/<id>`, ссылки для меток: `/badges` |

## Как работает подбор

1. **Совместимость целей.** Матрица: «ищу работу» ↔ «нанимаю», «ищу ментора» ↔ «стану ментором» (ментор опытнее на 3+ года), кофаундеры с дополняющими ролями (технарь + бизнес).
2. **Направление.** Совпадение семейства ролей (backend, data, design…).
3. **Текстовая близость.** TF-IDF по символьным n-граммам текста «о себе», стека и интересов. Работает для казахского, русского и английского без внешних моделей.
4. **Стек, интересы, опыт.** Пересечения и подходящая разница в опыте.
5. **Взаимность.** Скор считается в обе стороны и объединяется гармоническим средним: рекомендуем тех, кому вы тоже полезны.
6. **Разнообразие (MMR).** В топ-5 не попадают почти одинаковые люди.
7. **Объяснение и первая фраза.** Строятся по фактам (общий стек, цели, интересы); при наличии ключа их переписывает LLM (таймаут 2,2 с, затем откат на шаблон).

Время ответа без LLM ≈ 50–60 мс на 200 анкет.

## NFC-бейджи

На бейдж каждого участника клеится NFC-метка (или печатается QR) со ссылкой `https://<сайт>/p/<id>`.
Участник прикладывает телефон, и открывается страница: процент совместимости, почему стоит познакомиться,
первая фраза и общий свободный слот. Если своей анкеты ещё нет, сервис предложит заполнить её и вернёт к бейджу.
Ссылки для записи на метки: `/badges`. Записать метку можно бесплатным приложением NFC Tools (запись → URL).

## Живые бейджи участников

Каждый, кто заполнил анкету, получает свой бейдж: ссылку `/p/<id>` на странице подбора.
Её можно записать на NFC-метку прямо с телефона на Android (Chrome), либо через NFC Tools.
Анкета сразу попадает в базу, и другие участники видят её в подборе и могут тапнуть её бейдж.
Отмеченные знакомства видны в блоке «Мои знакомства» и на дашборде (`/dashboard`).

## API

- `POST /api/recommend` — `{session_id, lang, profile:{name, role, stack[], experience, interests[], about, goal, slots[]}}`
- `POST /api/feedback` — `{session_id, target_id, verdict:"met"|"bad", reason:"goal"|"role"|"other"}`
- `POST /api/pair` — `{session_id, target_id, lang}`: совместимость с владельцем бейджа
- `GET /api/stats` — данные для дашборда, включая `met_total` и `live` — данные для дашборда

## Данные

Все анкеты синтетические, имена и компании вымышлены. Генератор: `data/generate_profiles.py` (цели сбалансированы, чтобы у любой цели были пары).
